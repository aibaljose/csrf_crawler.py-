# CSRF Vulnerability Scanner & PoC

This project includes a Python-based crawler that scans websites for CSRF vulnerabilities and a Proof of Concept (PoC) HTML file to demonstrate exploitation.

## 🔍 Features

- Crawls a target URL and finds all forms
- Detects forms missing CSRF tokens
- Generates PoC HTML for CSRF exploit

## 🛠 Usage

1. Run the crawler:

2. Open the `csrf_poc.html` file in a browser to simulate an attack.

## 📂 Structure

- `csrf_crawler.py`: Scans for CSRF-vulnerable forms
- `csrf_poc.html`: Auto-submitting malicious form
- `README.md`: Project overview
